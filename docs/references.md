## Data-use note
The NBER-hosted source page states that the data are distributed for attributable non-commercial use (CC BY-NC) and asks users to cite the associated papers.

## Unit note
Published Dehejia–Wahba documentation describes RE74 and RE75 as real earnings in 1982 U.S. dollars and the experimental outcome RE78 in the same earnings framework. This repository labels its threshold grid as historical 1982 U.S. dollars and does not convert the results into current purchasing power.
