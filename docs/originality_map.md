# Portfolio Distinctness

## Closest neighboring portfolio themes
- causal learning analytics;
- learning experiment platforms;
- training transfer analytics.

## Why this bundle is distinct
This repository does not develop a new causal estimator or a generic experiment platform. It starts from a historical randomized training benchmark and studies **decision-threshold sensitivity**: how a fixed estimated treatment effect and its resampling distribution compare with alternative hypothetical minimum-benefit rules.

## Distinctness dimensions
1. **Unit:** randomized program participants.
2. **Question:** effect evidence versus minimum-benefit thresholds.
3. **Source:** National Supported Work experimental benchmark.
4. **Method:** difference in means + bootstrap + permutation diagnostic + threshold frontier.
5. **Output:** reproducible decision-sensitivity frontier.

“Original” means distinct within this portfolio. It does not claim that bootstrap analysis, permutation tests, or decision thresholds are new methods.
