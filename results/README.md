# Results

`empirical_summary.json` is the machine-readable release summary for **Decision Value of Training Evidence**.

It records:
- the Dehejia–Wahba RE74 subset definition;
- historical 1982-dollar outcome definition;
- sample sizes and group means;
- observed mean difference;
- Welch standard error;
- large-sample interval;
- bootstrap percentile interval;
- bootstrap exceedance diagnostics;
- treatment-label permutation diagnostic;
- threshold-frontier crossing points;
- interpretation boundaries.

The summary is generated from the same pipeline as the CSV evidence and figures and should not be edited independently.
